# 微信小程序 · 内部工具 UI 规范

> 文档路径：`d-ui/UI_SPEC_WX_MINI_INNER.md`  
> 适用范围：仓库 **`wx/wx-mini-inner/`**（EcoTea 内部作业小程序）  
> 产品说明见：`d-prd/PRD_WX_MINI.md`  
> **本文只约定视觉与交互基线；不替代 PRD。**  
> 其它小程序（若有）各自独立一份 `d-ui/UI_SPEC_*.md`，不混用本规范。

---

## 0. 规范治理（必读）

1. **先规范、后实现**  
   新增**业务模块**（如库存、财务、新单据类型）或新增**通用组件**（如步进器、状态标签、时间线）时，须**先在本文（或同目录增补章节 / 子文档）定义 UI 规范**，再写页面与样式代码。禁止「先上线、后补规范」。

2. **改规范再改存量**  
   Token、组件形态、强调色用法若调整，先改本文，再改 `wx-mini-inner`；避免代码与文档长期分叉。

3. **一程序一规范**  
   本文件仅服务 `wx-mini-inner`。C 端或其它小程序另立文档，可引用同一套方法论，但色板与组件表各自定稿。

4. **与 H5 的关系**  
   不对齐对内 H5 的 1:1 排版；可复用信息架构与字段，视觉以本规范为准。

5. **验收导向（内部工具 KPI）**  
   UI 是否合格，优先看：更快找到货、更少开错线/错店、数字改得稳、单据状态看得清——不是品牌感或装饰完整度。

## 1. 设计定位

| 项 | 约定 |
|----|------|
| 产品气质 | 店内作业工具：清晰、省步、少装饰、偏信息密度 |
| 主题 | **仅浅色**；本期不做暗黑 / 换肤 |
| 技术 | 原生微信小程序组件 + WXSS；优先系统导航栏、Tab、Toast、半屏能力 |
| 设计稿宽度 | 750；单位 **rpx**（下文尺寸均为 rpx，除非注明 px） |
| 不做 | 大插画空态、复杂动效、消费级营销布局、整页换肤 |

### 1.1 信息密度

- 价目 / 单据列表：一屏多行优先；忌大留白、大图卡堆叠。  
- 次要说明用 secondary 字色与 22～24 字阶，可省略则省略。  
- 筛选默认收在顶区芯片，勿占半屏。  
- 列表行高度约 **112～128**；双行文案时仍保持紧凑。

## 2. 色彩策略（定稿）

**一个小程序、一种壳；销售 / 回收两条业务线只用强调色做防呆，不做整页换肤。**

| 层级 | Token | 色值 | 用途 |
|------|-------|------|------|
| 壳主色 | `--color-brand` | `#0f766e` | Tab 选中、通用主按钮、登录主 CTA、链接强调、全局进度 |
| 壳浅底 | `--color-brand-soft` | `#e6f4f2` | 壳相关浅底、轻提示 |
| 销售强调 | `--color-sale` | `#3d5a3d` | **仅销售线**：选中芯片、线别标签、销售主操作钮 |
| 销售浅底 | `--color-sale-soft` | `#e8efe6` | 销售线选中浅底 |
| 回收强调 | `--color-recycle` | `#b45309` | **仅回收线**：同上 |
| 回收浅底 | `--color-recycle-soft` | `#fff7ed` | 回收线选中浅底 |

### 2.1 中性与语义（全模块共用）

| Token | 色值 | 用途 |
|-------|------|------|
| `--color-bg-page` | `#f3f5f1` | 页面底 |
| `--color-bg-card` | `#ffffff` | 卡片、列表底、导航栏底 |
| `--color-border` | `#d8ddd6` | 分割线、描边 |
| `--color-text-primary` | `#1c241c` | 正文、标题 |
| `--color-text-secondary` | `#6b756c` | 次要说明、辅助 |
| `--color-text-disabled` | `#9ca3af` | 不可点、占位弱化（勿再更浅） |
| `--color-price` | `#b45309` | 金额展示（语义色，跨线通用） |
| `--color-price-line` | `#f5d0a9` | 金额相关浅描边（折扣、清空类次按钮） |
| `--color-danger` | `#9a3412` | 错误、作废、破坏性操作文案 |
| `--color-scarce` | `#c2410c` | 紧缺 / 低库存提示 |
| `--color-mask` | `rgba(0,0,0,0.5)` | 半屏 / 弹层遮罩 |
| `--color-success` | `#0f766e` | 成功提示（可与 brand 同色） |

### 2.2 价格色与回收强调色同色时的区分

`--color-price` 与 `--color-recycle` 同为 `#b45309`。回收线内：

- **金额**：用价格字阶（36～40）+ 字重 `600`，不必再加描边底。  
- **线别强调**（芯片选中、主 CTA）：用 `--color-recycle` / soft，靠组件形态区分，不单靠颜色。  
- 销售线无此冲突（绿强调 vs 琥珀价）。

### 2.3 强调色白名单 / 黑名单

**允许（销售或回收页内）：** 筛选芯片选中、线别小标签、该线主 CTA、可选列表左边线。  

**禁止：** 导航栏 / Tab 随模块变色；整页背景换色；登录 / 选店 / 首页 / 工作台 / 我的把 sale/recycle 当主色（工作台入口图标可用 soft 底区分分组）。

### 2.4 模块扩展

1. 默认只用壳主色 + 中性 + 语义色；  
2. 仅存在「易混淆、需防呆」的对等业务线时，才新增 `--color-{domain}` 对，并先写入本文；  
3. 不为装饰加第三套品牌色。

### 2.5 对比度（店内光线）

- 主按钮：brand / 强调色底 + **白字**，保证可读。  
- secondary 用于辅助即可；正文与关键数字用 primary / price。  
- disabled 用 `--color-text-disabled`，勿仅靠降低透明度。

## 3. 字体：字阶与字重

| 术语 | 含义 | 本规范 |
|------|------|--------|
| **字阶** | 字号层级（多大、用在哪） | 下表 22～40 |
| **字重** | 笔画粗细 | 常规 `400`、强调 `600` |

- 字体：系统默认；**不**引入自定义字体包。  
- 字重 `600`：小标题、价格、主按钮文案、合计数字。

| 角色 | 字号（字阶） | 行高建议 |
|------|--------------|----------|
| 辅助 / 角标 / 状态字 | 22 | 1.3 |
| 次要说明 | 24 | 1.4 |
| 正文 / 列表主文 | 28 | 1.4 |
| 小标题 / 分组名 | 32 | 1.3 |
| 价格 / 关键数字 / 合计 | 36～40 | 1.2 |
| 页标题 | 跟系统导航栏 | — |

金额展示尽量对齐（右对齐或等宽数字观感）；改价输入框字阶不低于正文。

## 4. 间距与圆角

### 4.1 间距阶梯

`4 / 8 / 12 / 16 / 24 / 32 / 40 / 48`

| 场景 | 取值 |
|------|------|
| 页面左右边距 | 32 |
| 卡片内边距 | 24 |
| 卡片之间 | 16～24 |
| 列表行上下内容边距 | 24 |
| 底栏按钮区内边距 | 16～24（含安全区） |

### 4.2 圆角

| 场景 | 圆角 |
|------|------|
| 输入框 / 小控件 | 8 |
| 芯片 / 小按钮 / 状态标签 | 12 |
| 卡片 / 分组容器 | 16 |
| 半屏弹层顶角 | 24 |
| 工作台入口图标底 | 24 |

### 4.3 触控

- 主按钮高度：**88**；次要：**72～80**；热区短边 ≥ **72**。  
- 列表行约 **112～128**。

## 5. 组件规范

### 5.1 按钮

| 类型 | 视觉 | 使用 |
|------|------|------|
| Primary | 底 brand（或业务线强调色），字白 | 主操作 |
| Secondary | 白底 + 描边 2，字同描边色 | 次要、双按钮中的非破坏侧 |
| Ghost / 弱 | soft 底或纯文字 | 工具型（复制、扫码旁） |
| Danger 文案钮 | 字 `--color-danger`，或确认框内「破坏」侧 | 作废、删除、清空 |
| Disabled | 浅灰底 + disabled 字色 | 不可点 |

底栏：优先单主按钮全宽；双操作时主视觉给正向操作，破坏性操作用文案色或放次要位。

### 5.2 芯片（筛选）

- 默认：浅灰/白底 + border，字 secondary。  
- 选中：线 soft 底 + 强调色描边与文字；壳层筛选用 brand。  
- 高度约 56～64；左右内边距 20～24。

### 5.3 状态标签（单据必用）

用于报价单 / 销售单 / 回收单列表与详情。形态：圆角 12、字 22、左右内边距 12～16。

| 状态（示意） | 视觉 | 说明 |
|--------------|------|------|
| 草稿 / 编辑中 | 灰底 + secondary 字 | 未确认 |
| 有效 / 已确认 | brand-soft 底 + brand 字 | 正向进行中 |
| 已转单 | 中性描边 + primary 字 | 已流转，只读倾向 |
| 已作废 | 浅红/浅橙底 + danger 字 | 终态 |

具体状态枚举以 PRD / 接口为准；**新增状态须先补本表再上线**。同一状态在列表与详情用同一套标签。

### 5.4 搜索条

- 圆角 12～16；左搜索，右可选扫码。  
- 固定列表顶区；吸顶可选。

### 5.5 列表行

- 白底；分割线或卡片间距二选一，列表内统一。  
- 左：标题 + 次要信息；右：价格或状态标签。  
- 无货 / 停用：降对比，不拆布局。

### 5.6 卡片 / 分组

- 白底、圆角 16、内边距 24；少阴影，用页底色分层。

### 5.7 半屏 / 居中弹层

- 遮罩 `--color-mask`；半屏贴底顶圆角 24；高度不超过导航下沿；保留安全区。

### 5.8 开关 / 单选 / 多选

- 原生组件优先；选中色 brand（业务线表单内可用强调色）。

### 5.9 空态 / 加载 / Toast

**空态（短文案，无大插画）：**

| 场景 | 文案方向 |
|------|----------|
| 列表无数据 | 「暂无数据」+ 可选清空筛选 |
| 工作台全部无权限 | 「暂无可用功能，请联系店长开通权限」 |
| 搜索无结果 | 「未找到相关商品」 |
| 加载失败 | 「加载失败」+「重试」按钮 |

**Toast：** 成功「已复制」「已保存」「已提交」；失败用接口/业务短句，勿技术堆栈。  
**Loading：** 系统 loading 或 brand 色；提交中按钮进入 disabled + loading。

### 5.10 危险操作确认

下列必须用 `wx.showModal`（或等价居中确认），确认钮用破坏语义：

| 操作 | 提示要点 |
|------|----------|
| 作废报价单 / 业务单 | 说明作废后不可恢复（或按产品规则） |
| 清空开单篮 | 说明将移除全部行 |
| 删除单据行 | 点名品名或「该行」 |
| 其它不可逆写操作 | 先补本表再实现 |

轻量可撤销操作（如取消勾选）不必弹窗。

### 5.11 金额与改数

- 列表价、详情价、行约定价、单据合计：字阶 36～40 或至少比正文大一档；合计区在编辑页**吸底可见**（与底栏并存时，合计在底栏上方）。  
- 改数量 / 改约定价：失焦或确认后生效；非法输入 Toast 提示，不静默吞掉。  
- 合计变化应即时可见。

### 5.12 开单篮入口

- 价目列表 / 详情进入开单篮的入口位置在同一业务线内保持一致（底栏或顶栏右侧二选一，优先底栏）。  
- 篮内有商品时显示**数量角标**（红点或数字徽标）；角标不超过两位数显示规则自定但全端统一。  
- 销售篮与回收篮物理分离（产品已定分流）；UI 上用线别强调色区分入口，避免共用一个篮图标却进错线。

### 5.13 工作台入口

- 每行 4 列；图标容器约 96×96，圆角 24，底可用分组 soft。  
- 标题 24；**无对应 perm 的入口不展示**（见 §6.2）。

## 6. 导航、店铺与权限呈现

### 6.1 导航壳

| 区域 | 约定 |
|------|------|
| 导航栏 | 白底，标题黑字 |
| Tab | 未选 `#999999`，选中 `#0f766e`，白底 |
| 页面底 | `--color-bg-page` |
| 自定义顶栏 | 右侧操作 ≤ 2 个 |

### 6.2 当前店铺（防开错店）

已登录且已选店后，须在壳层**常显当前店铺名称**（至少一处）：

- 优先：首页 / 工作台 / 我的顶区；或  
- 导航栏标题副文案 / 自定义顶栏副标题。  

切换店铺入口放在「我的」（与 PRD 一致）。未选店不得进入业务页。

### 6.3 权限与可见性

| 情况 | UI |
|------|-----|
| 工作台某入口无 perm | **不展示**该入口；分组内全无则隐藏分组 |
| 工作台全部无入口 | 空态文案见 §5.9 |
| 深链 / 旧路径进入无权限页 | 提示「无权限」并提供返回工作台，不白屏 |
| 首页快捷 | 同样受 perm 约束 |

## 7. 页面模板

1. **列表 + 顶筛**：搜索/芯片 → 列表 → 可选底栏（开单篮）。  
2. **详情 + 底栏**：内容滚动；底栏 1～2 主操作。  
3. **表单 / 选店**：分组卡片 + 底栏提交。  
4. **单据编辑**：行列表 + **合计吸底** + 提交/作废。  
5. **单据列表**：状态筛选芯片 + 行内状态标签。  
6. **结果 / 预览**：主信息 + 主按钮（按产品需要）。

## 8. Token 是什么 & 如何落地

### 8.1 Token 含义（给非设计同事）

**Token（设计令牌）** = 规范里命名好的一组「设计变量」，例如颜色 `--color-brand`、间距阶梯、圆角档位。  

代码里写成 CSS 变量（WXSS），页面用 `var(--color-brand)`，而不是到处写死 `#0f766e`。  

好处：改一处壳色，全端跟着变；评审时也能对照本文表格。

「**新页强制用 Token；旧页有空再抠**」= 新写的页面样式必须引用这些变量；已经上线的旧页不要求立刻改完，有空再把硬编码色值换成变量。

### 8.2 落地步骤（文档定稿后）

> 改代码时再执行；本节先约定目标。

1. 新增 `miniprogram/styles/tokens.wxss`（写入 §2～§4 变量），`app.wxss` 引入。  
2. `sale-theme` / `recycle-theme` 只映射强调色，中性色走全局 tokens。  
3. **新页面**：禁止散落硬编码色值 / 随意字号；用 Token + 本组件表。  
4. **旧页面**：渐进替换，不挡功能迭代。  
5. 新增组件 / 状态：先改本文，再写代码。
