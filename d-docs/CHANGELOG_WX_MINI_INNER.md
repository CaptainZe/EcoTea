## 发布 checklist

- [ ] 打开的是本工程，AppID 为 `wx28864054909d5425`
- [ ] `miniprogram/config/env.ts` 的 `CURRENT_ENV` 改为 `prod`（`https://api.ecotea.cn`）。当前默认是 `dev`，指向局域网地址，正式包不能用
