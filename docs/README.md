# EcoTea 文档

仓库文档统一放在 `docs/` 下（由原顶层 `d-*` 目录整合）。

| 目录 | 职责 |
|------|------|
| [`prd/`](prd/) | 产品需求与规划（`PRD_*.md`） |
| [`deploy/`](deploy/) | 部署与运维（`DEPLOY_*.md`） |
| [`ui/`](ui/) | 各端 UI 规范（如 `UI_SPEC_WX_MINI_INNER.md`） |
| [`db/`](db/) | SQL 脚本与库表文档（含 `tmp/` 增量） |
| [`scripts/`](scripts/) | 文档/运维辅助脚本 |
| [`dev/`](dev/) | 编码约定、TODO、changelog（`CODING_*` / `TODO_*` / `CHANGELOG_*`） |

新增文档时按上表归类。
