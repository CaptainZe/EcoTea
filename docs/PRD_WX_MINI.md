# 微信小程序 · 内部工具 MVP（PRD）

> 文档名：`PRD_WX_MINI.md`  
> 范围：EcoTea **内部作业小程序**产品说明（查在售、生成销售图、销售/回收开单）。  
> 对外获客仍走 **订阅号 + H5**（见 `PRD_WX_MP.md`）。  
> **本期不做服务号；全链路不做线上收款付款。**  
> 本文只描述产品能力与页面，不涉及表结构、接口与实现细节。

---

## 1. 目标与定位

| 维度 | 说明 |
|------|------|
| 对内定位 | 店员 / 经营者的 **作业工具**：查货、出销售图、记销售单与回收单 |
| 对外定位 | **不作为** C 端卖货入口；顾客仍通过订阅号菜单进入 H5 |
| 收款 | **不提供**任何在线收款 / 付款；单据中的金额仅为约定记录，便于对账与跟进 |
| 文案 | 对 C 端文案不出现 EcoTea；小程序对内可用内部称呼；对外简介偏「库存查询 / 单据工具」 |

| 触点 | 作用 | 本期 |
|------|------|------|
| 订阅号 + H5 | 推广、在售价目、回收引流、客服 | 已有，继续主阵地 |
| 本小程序 | 登录后的内部查价、出图、开单 | MVP |
| 服务号 | 服务触达、授权等 | **不做** |

**主体（已定）：** 使用 **个体工商户** 注册、认证并备案后发布正式版；不采用个人主体作为正式方案。

---

## 2. 使用对象与权限

| 角色 | 谁 | 能做什么 |
|------|----|----------|
| 管理员 | 经营者 | 全部查价（含回收参考价）、开单、作废单、查看全部单据；管理员工账号（可在后台完成） |
| 店员 | 员工 | 查在售、生成销售图、销售/回收开单、查看与自己相关的单据 |

- 必须先登录，未登录不能使用任何业务功能。  
- MVP 以账号密码登录为主；微信一键登录可后续再做。

## 3. 功能清单

### 3.1 必须有（MVP）

| 编号 | 功能 | 说明 |
|------|------|------|
| F1 | 登录 / 退出 | 员工账号登录；停用账号不可用；可退出 |
| F2 | 在售列表 | 按品牌 / 品名搜索；展示售价、库存；无货需可识别（如标灰或「无货」） |
| F3 | 在售详情 | 品名、规格等基础信息、展示图、售价、库存；支持进入出图、复制对外链接、带入销售开单 |
| F4 | 生成销售图 | 生成用于发给客户的图片（含品名、关键规格、售价等）；可保存到手机；图上 **不出现** 支付入口、回收价 |
| F5 | 复制对外详情链接 | 复制给客户可打开的对外 H5 详情地址（与订阅号价目一致） |
| F6 | 销售开单 | 可多行商品；填数量、约定单价 / 总价、客户备注；保存为内部单据 |
| F7 | 回收开单 | 可参考回收价（仅登录内部可见）；可选手填品名 / 成色备注；保存为内部单据；**无收款** |
| F8 | 单据列表与详情 | 按销售 / 回收、状态筛选；可查看明细；支持草稿 → 已确认 → 已完成，以及作废 |

### 3.2 后续可做（非 MVP）

| 编号 | 功能 |
|------|------|
| F9 | 微信一键登录并绑定员工 |
| F10 | 开单确认后自动联动出入库 |
| F11 | 在小程序内直接管理员工 |
| F12 | 单据分享给同事 |
| F13 | 扫码查货 / 开单 |
| F14 | 从订阅号菜单给员工入口（需控制暴露范围） |

### 3.3 明确不做（本期）

- 微信支付或任何在线收付款  
- C 端商城、下单、购物车支付  
- 服务号及模板 / 订阅类服务通知  
- 向 C 端（订阅号 H5）暴露回收价、成本  
- 用小程序替代订阅号做对外推广主阵地  
- 粉丝 / 会员体系

## 4. 页面结构

```
小程序
├── 登录
├── Tab「在售」
│   ├── 在售列表（搜索）
│   └── 在售详情
│       ├── 生成销售图（预览 → 保存）
│       ├── 复制对外详情链接
│       └── 去开销售单（带入当前商品）
├── Tab「开单」
│   ├── 销售开单
│   ├── 回收开单
│   └── 单据列表 → 单据详情（改状态 / 作废）
└── Tab「我的」
    ├── 当前账号信息
    └── 退出登录
```

| 页面 | 作用 |
|------|------|
| 登录 | 账号密码进入系统 |
| 在售列表 | 快速找货、看价与库存 |
| 在售详情 | 看清商品信息，并出图 / 复制链接 / 开销售单 |
| 销售图预览 | 确认海报内容后保存到相册 |
| 销售开单 | 录入销售约定（商品、数量、金额、客户备注） |
| 回收开单 | 录入回收约定（可参考回收价，可手填） |
| 单据列表 | 按类型、状态找历史单 |
| 单据详情 | 查看明细，推进或作废状态 |
| 我的 | 账号与退出 |

**三个 Tab：** 在售 | 开单 | 我的。  
回收相关能力只出现在「回收开单」等内部流程，不作为对外宣传页。

## 5. 关键业务规则（产品层）

1. **对外 / 对内分离**  
   - 顾客：订阅号 → H5 看在售、看回收说明、加客服。  
   - 员工：小程序登录后查货、出图、记单。

2. **价格展示**  
   - 销售价：列表、详情、销售图均可展示。  
   - 回收参考价：仅登录后的回收开单（及必要的内部详情）可见；不得出现在销售图、对外链接对应页面。

3. **库存**  
   - 列表 / 详情展示库存；无货仍建议可查（便于回复询价），但需明确「无货」状态。  
   - MVP **不要求**开单后自动改库存；确认成交后可在后台另行处理出入库。

4. **单据金额**  
   - 仅为双方约定记录，用于跟进与对账；界面与文案避免「支付」「付款」「收银台」等表述。

5. **单据状态（建议）**  
   - 草稿 → 已确认 → 已完成；任意未完成态可作废（作废后不可再当有效单使用）。

4. 服务号本期不申请、不接入。

---

## 8. 验收要点

1. 未登录无法查货、出图、开单。  
2. 销售图与对外链接路径中，无支付入口、无回收价。  
3. 回收参考价仅出现在登录后的回收相关流程。  
4. 销售单、回收单均可创建，可查看，可推进状态或作废；金额仅为约定记录。  
5. 全程无在线收付款相关能力与文案。  
6. 对外获客路径仍以订阅号 + H5 为主，小程序不替代该路径。
