# 订阅号 · 核心品回收价日报草稿（待实现）

> 状态：**待排期**；订阅号侧接口权限已确认（素材 / 草稿 / 发布均「有权限」）。  
> 相关：[`PRD_WX_MP.md`](../prd/PRD_WX_MP.md)、[`SPU_MARK.md`](../prd/features/SPU_MARK.md)（`core_flag`）。  
> **本期边界**：先打通「素材列表可见 media_id → api 定时写草稿」；**版式模板与取数细则另定**（本 TODO 不锁死）。

## 1. 目标

| 项 | 结论 |
|----|------|
| 业务 | 每日将「核心产品」回收价整理成图文，写入订阅号**草稿箱**（可先人工点发布） |
| 入选 | `core_flag = 1`（及后续另定的上架/有价等条件） |
| 素材 | **不在 Admin 做上传**；人在公众平台「素材管理」传永久素材；Admin/api **拉列表展示 media_id** |
| 自动发布 | **后置**；MVP 只 `新增草稿`，发布用后台或后续再调「发布草稿」 |

## 2. 已具备（订阅号）

## 3. 分期

### Step A · 永久素材列表（Admin 可见 media_id）【先做】

| 项 | 说明 |
|----|------|
| 上传 | 继续用公众平台素材库（永久素材） |
| api | 调微信「获取永久素材列表」（按 type=image 等分页）；可选落本地缓存表 |
| admin | 微信生态下「素材」页：名称、类型、`media_id`、图片 url、更新时间；支持刷新同步 |
| 鉴权 | 与菜单发布相同：admin → api（`X-EcoTea-Api-Key`），**禁止**浏览器直连微信 |
| 不做 | Admin 上传到微信；临时素材列表 |

### Step B · 定时生成草稿【依赖 A + 出图】

| 项 | 说明 |
|----|------|
| 定时 | api `@Scheduled` 或外部 cron 打带密钥内部接口 |
| 取数 | 核心品 + 回收价（**规则另定**） |
| 出图 | **服务端**渲染多图（模板另定）；小程序 Canvas 不复用 |
| 上传图 | 正文图优先「上传图文消息内的图片」得 url；封面用永久素材 `media_id`（可来自 Step A 选定） |
| 草稿 | `draft/add`；标题/作者/摘要可配置；失败告警可查 |
| 发布 | MVP 不自动调；稳定后再开「发布草稿」并处理订阅号日配额 |

### Step C · 后置（明确不做或另开 TODO）

- 版式精修、涨跌色、分区规则产品定稿  
- 全自动发布 + 失败重试/钉钉告警  
- 核心品专题 H5 / Redis 热读（见 SPU_MARK「本版不做」）  
- JS-SDK 相关

## 4. 工程约定（实现时）

- 微信调用集中在 **server-api**（WxJava 已有 `WxMpService`）。  
- admin 仅配置/展示/触发同步；写操作走 api-key。  
- 配置项建议：封面 `media_id`、草稿标题模板、是否启用定时、cron 表达式、作者等（可先 `wx_global_config` 新 type 或独立表，实现时定）。  
- 定稿后并入 `prd/features/`（含测试用例），再删本 TODO；发版记 CHANGELOG。

## 5. 测试用例（草稿）

| # | 场景 | 步骤要点 | 期望 |
|---|------|----------|------|
| 1 | 素材同步 | 公众平台传一张图 → Admin 点刷新 | 列表出现该图，`media_id` 非空，可复制 |
| 2 | 鉴权 | 无 Api-Key 调同步接口 | 拒绝 |
| 3 | 生成草稿 | 手动触发一次「生成核心品草稿」（有封面 media_id） | 公众平台草稿箱新增一条；正文含图 |
| 4 | 空数据 | 无核心品或无回收价 | 不写草稿或写占位策略按实现约定；有明确日志 |
| 5 | （后置）发布 | 对草稿调发布 | 成功或配额耗尽有可读错误 |
